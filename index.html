dotimg

compress one image, video, gif, song, midi, data, table, subtitle, code or archive file down to a size you pick. everything happens in this browser. nothing is uploaded anywhere.

how it works

pictures are re-encoded over and over at different sizes until one lands under your target, keeping quality at a readable level and shrinking the picture rather than smearing it. video and sound are given a bitrate worked out from how long they run, then re-encoded and corrected until the file fits. gifs are rebuilt with a new colour palette, dropping frame rate and colours as needed. a midi file holds notes rather than sound, so it is rewritten instead: names and lyrics go first, then controllers, then musical detail, and it will never hand back a silent file.

text, code and data are different: nothing in them can be thrown away without changing what they mean, so they have a floor. json, yaml, tables and subtitles are rewritten as compactly as their format allows, and can be converted into a close relative, such as json into yaml. javascript, css and html go through real minifiers, never simple whitespace stripping.

archives are unpacked and packed again with 7-zip, at its strongest settings. nothing inside is changed: every file and folder comes back exactly as it was. rar, iso and similar formats can be opened but not written, and password protected archives are left alone.

some things are not possible and the page will say so rather than fail quietly. heic needs apple's decoder and only works in safari. camera raw differs for every manufacturer. every format also has a smallest possible size from its own headers, and if your target is below that, the page tells you the floor and offers the smallest file it managed.
